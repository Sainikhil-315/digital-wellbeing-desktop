✦ Features

Everything you need.
Nothing you don't.

Powerful tools working together, all running silently in the background.

Screen Time Tracking

Polls the active window every 5 seconds. Records app usage to a local SQLite database — no cloud sync, no privacy risk. See exactly where your time goes.

App Limits

Set daily time limits per app. Get warned at 80% and blocked at 100%. Visual progress bars show exactly how close you are to your limit in real time.

App Usage & Categories

Full table of every app tracked today — time, open count, and category. Click any category pill to override it. Changes persist and are never overwritten automatically.

Weekly Reports

7-day bar chart, streak tracking, and productive vs. distraction breakdown. Understand your patterns and see week-over-week improvement.

System Tray Mode

Runs silently in the background. Window hides on close. Tray icon gives instant access. Auto-launches at Windows startup so tracking never misses a beat.

Auto-Updates

Checks GitHub Releases every 4 hours. Shows a download progress banner inside the app. One-click relaunch installs the latest version — always stay current.

✦ How it works

Up and running
in 60 seconds.

Install, launch, and start tracking. No configuration required to get started.

1

Download & Install

Run the NSIS installer — no admin tricks, no bloatware. Pick your install directory, click Next twice, done. Takes under 30 seconds.

2

Track Automatically

The app launches into your system tray and starts tracking immediately. No setup needed — it silently records every app you use in the background.

3

Set Limits & Review

Open the app from the tray to set daily app limits with hard or soft enforcement. Check your weekly report to spot patterns and watch your productivity score improve over time.
